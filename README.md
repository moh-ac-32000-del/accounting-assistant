# Accounting Assistant

Cloud-first mobile accounting application for small retail businesses.

## Project principles

- No Replit dependency.
- GitHub is the source repository.
- Firebase / Google Cloud is the authoritative backend for business and financial data.
- Expo / React Native is the mobile application framework.
- EAS will be used for builds and distribution.
- Local storage is limited to UI preferences, cache, and non-authoritative drafts.
- Sensitive financial mutations use trusted backend commands and Firestore transactions.
- Security and data integrity are release requirements.

## Current stage

Architecture and foundation setup.

The legacy repository `My-app` is retained only as a product and implementation reference. It is not the codebase for this project.
